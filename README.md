# Statistics Calculator

Statistics Calculator is a Python application I created to make common statistical calculations easier and provide the results in one place.

I originally built the calculator while taking an applied statistics course. I continued expanding it as I learned new statistical methods and wanted a tool that could perform the calculations without having to use several different calculators or websites.

## Features

The Statistics Calculator can perform a variety of statistical calculations including:

- Mean
- Median
- Mode
- Variance
- Standard deviation
- Confidence intervals
- Z-tests
- T-tests
- Paired t-tests
- Independent t-tests
- One-tailed and two-tailed hypothesis tests
- P-value calculations
- Other common descriptive and inferential statistics

## Purpose

The goal of the project is to make statistical calculations easier to perform and understand.

Instead of using separate tools for different calculations, the application provides a single place to enter data and perform statistical analysis.

Building the calculator also gave me a practical way to apply both Python programming and the statistical concepts I was learning.

## Technologies

- Python
- Statistical formulas and calculations
- Data input and validation
- Python-based user interface

## What I Learned

This project helped me combine programming with applied statistics. Developing the calculator required me to understand not only how to implement statistical formulas in Python but also when different statistical methods should be used.

As I added features, I also worked on organizing the program so different calculations could be handled without making the application difficult to maintain or use.

## Project Status

The Statistics Calculator is a personal project that I continue to update as I learn and add additional statistical functions.
